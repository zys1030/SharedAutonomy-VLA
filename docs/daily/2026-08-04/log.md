## 新结论与决策

- **200k 已初步突破原有瓶颈**：本轮现场诊断达到 17/22；相较旧 `r4_critical` 100k 的 6/18，失败已不再主要表现为大范围水平失准。
- **当前误差转为小幅、可微调的 XY 残差**：成功样本中常见偏近/偏远 2–3 mm；失败样本主要集中在偏近 5–7 mm 或偏右偏近约 1 cm。
- **夹爪冗余确实提供容错**：右远和右中偏远在存在明显水平偏差时仍成功，但这类成功不能直接证明策略输出已把把手中心对准。
- **仍有抓起后的稳定性问题**：短边中远出现抓到、抓起后掉落，后续需把「闭合成功」与「完整抓起并保持」分开记录。
- **重算卡顿是新的可见问题**：打圈不明显，但每次重算的卡顿明显；后续应测量重算间隔/推理耗时，和模型几何误差分开排查。
- **主力 checkpoint 暂定 200k**：150k 长边轻量 2/5、100k 短边轻量 1/5，均未优于 200k 的 17/22；远点偏近是三个 checkpoint 的共性弱点，但 200k 在近中格点仍最稳。
- **100k / 150k 对照为轻量探测**：未做与 200k 相同的全格点复测，结论限于「远点/弱点格点上未见更好」；正式 benchmark 仍以 200k 为主。

## 今日理解重点（15–30 分钟）

### 1. 抓取成功与把手中心对准不是同一个指标

- **一句话**：夹爪宽度和冗余可以把有偏差的策略输出转化为成功抓取。
- **为什么重要**：只看成功率会掩盖模型仍存在的系统性 XY 偏差，后续换物体或姿态时可能暴露。
- **本项目怎么做**：同时记录偏差方向、偏差量、是否依靠夹爪冗余成功。
- **代码入口**：`scripts/rollout_act_policy.py`、`scripts/plot_grasp_close_xy.py`。
- **自测问题**：为什么「抓取成功」不能单独证明策略已经准确对准把手中心？

### 2. 训练 loss 与 checkpoint 真机效果要分开评价

- **一句话**：loss 反映训练目标上的拟合程度，不能直接替代真实抓取成功率和稳定性。
- **为什么重要**：200k loss 已降到 `0.024–0.025`，但仍存在掉落、偏近和重算卡顿。
- **本项目怎么做**：用 100k / 150k / 200k checkpoint 做同口径首次抓取对照，再决定主力 checkpoint。
- **代码入口**：`scripts/rollout_act_policy.py`、`scripts/train_act_critical.py`。
- **自测问题**：为什么不能仅因为 200k 的 loss 最低就跳过 100k / 150k 的 rollout？

### 3. 首次抓取、抓起保持和放置应拆开记录

- **一句话**：闭合夹到物体、抓起后保持、最终放置是连续但不同的成功条件。
- **为什么重要**：短边中远「抓到抓起但掉落」说明闭合并不等于稳定完成任务。
- **本项目怎么做**：继续分别记录碰到、闭合、抓起、掉落和完整抓放。
- **代码入口**：`scripts/rollout_act_policy.py`。
- **自测问题**：一次抓起后掉落应该归为成功还是失败，为什么？

### 4. 重算卡顿与轨迹打圈是两个不同现象

- **一句话**：没有明显打圈只能说明方向振荡不突出，不能说明重算时延正常。
- **为什么重要**：卡顿会影响接近阶段的动作连续性，也可能与策略几何偏差混在一起。
- **本项目怎么做**：保持现有 `reset_every=25` 口径，单独检查 replan 时间与推理耗时。
- **代码入口**：`sharedautonomy/policies/act/rollout.py:145-150`、`:301-314`。
- **自测问题**：为什么「不打圈」不能推出「每次重算都足够流畅」？

## 自测参考答案

### 理解重点

1. **抓取成功与把手中心对准**
   - 参考答案：夹爪具有一定宽度和冗余，末端即使偏离把手中心仍可能夹住。因此成功率只能说明任务结果，不能单独说明 XY 对准精度。

2. **loss 与真机效果**
   - 参考答案：loss 只衡量训练数据上的优化目标；真机还受分布外姿态、夹爪容错、Z 高度、时延和控制执行影响，所以必须用同口径 rollout 选择 checkpoint。

3. **首次抓取、抓起保持和放置**
   - 参考答案：若抓到并抓起后掉落，说明闭合阶段可能成功，但完整抓取任务失败；应分别记录这些阶段，避免把不稳定成功统计成完整成功。

4. **重算卡顿与打圈**
   - 参考答案：打圈描述轨迹方向或位置的振荡，卡顿描述时间连续性或重算时延；轨迹不振荡时仍可能在每次 replan 发生明显停顿，二者需要分别测量。

### 面试式自测

1. **为什么 17/22 还不是正式 benchmark？**
   - 参考答案：本轮是现场诊断，包含不同朝向和非长短边正对尝试，样本量也有限，未与 100k / 150k 在完全相同的位置和口径下对照，所以只能说明明显改善，不能给出严格 benchmark 结论。

2. **夹爪冗余成功还应记录什么？**
   - 参考答案：应记录末端相对把手的 XY 偏差方向和大小、接触部位、是否偏边、是否完整抓起并保持，以及是否发生掉落。

3. **150k 与 200k 接近时看什么？**
   - 参考答案：应看首次成功率、偏差分布、失败类型、抓起保持稳定性、重算流畅度和结果方差，而不是只看训练 loss。

4. **如何拆分卡顿与偏差问题？**
   - 参考答案：为每次 replan 记录时间戳、推理耗时、控制发送耗时和动作间隔，同时独立记录每次闭合前的 XY/Z 偏差；这样可以分别判断时延是否导致动作停顿，以及几何偏差是否是策略输出问题。
