- **370k 相比 100k 的行为改善是可信的**：远侧中远、右远等点位已经可以稳定抓放，说明继续训练确实在改善 reaching。

- **但 370k 尚未整体超过 r5 200k**：远侧改善不均匀，左远仍失败；短边中远/右远仍有较大偏近。

- **当前更像“远侧收益与近侧稳定性之间的权衡”**，还不能断定是过拟合或新数据有害。
- **高步数早期有收益，但 370k → 400k 暂未见明显增益**：200k → 300k 有改善，370k 观感继续更好；400k 与 370k 接近，且测试集合不完全一致。

## 今日理解重点（15–30 分钟）

### 1. Checkpoint 选择需要看空间分布，而不是只看总成功率

- **一句话**：不同 checkpoint 可能改善远侧，却损伤近侧。
- **为什么重要**：总成功率可能掩盖位置分布上的回归。
- **本项目怎么做**：分别记录远/中/近、左右位置和偏差方向，再选择 checkpoint。
- **代码入口**：`scripts/rollout_act_policy.py`、`docs/datasets.md` §5。
- **自测问题**：为什么 370k 远侧变好，仍不能直接判定它比 r5 200k 更好？

### 2. 重复测试用于观察方差

- **一句话**：同一位置多次尝试的成功/失败差异，反映策略稳定性而不只是平均精度。
- **为什么重要**：右近 3 次仅成功 1 次，说明单次成功不能代表该位置可靠。
- **本项目怎么做**：对边界位置记录重复次数、成功次数和失败形态。
- **代码入口**：`scripts/rollout_act_policy.py`；现场 rollout 记录表。
- **自测问题**：为什么右近一次成功不能覆盖另外两次失败？

### 3. 夹爪冗余成功要与准确对准区分

- **一句话**：夹爪横向冗余能把偏差输出转化为成功，但不代表策略已经对准有效中心。
- **为什么重要**：左近偏左 1 cm 仍成功，不能据此认为左近定位准确。
- **本项目怎么做**：同时记录偏差、接触部位、是否依靠冗余和是否掉落。
- **代码入口**：`scripts/plot_grasp_close_xy.py`、`scripts/rollout_act_policy.py`。
- **自测问题**：为什么左近成功仍应标记为“依赖夹爪冗余”？

### 4. 何时停止堆 ACT 数据 / 步数

- **一句话**：当边际收益变成空间权衡（远侧↑、中部↓）且主力场景已可用时，应锁基线并换主线，而不是继续加步。
- **为什么重要**：求职闭环要展示「诊断→决策→下一系统能力」，不是无限抠单条件成功率。
- **本项目怎么做**：中部随机 r5 优于 r6 → 锁 r5-200k；主线改 SharedAutonomy。
- **代码入口**：[`docs/roadmap.md`](../roadmap.md)、[`docs/datasets.md`](../datasets.md) §5。
- **自测问题**：为什么远侧补采训到 400k 后仍选择 r5-200k 作基线？

## 自测参考答案

### 理解重点

1. **Checkpoint 选择与空间分布**
   - 参考答案：一个 checkpoint 可能改善远侧 reaching，同时让近侧偏差或稳定性变差；必须看分位置结果，不能只看总成功率。

2. **重复测试与方差**
   - 参考答案：同一点 3 次只有 1 次成功说明边界附近存在较高随机性或执行敏感性，一次成功不足以证明可靠。

3. **夹爪冗余与准确对准**
   - 参考答案：夹爪有效宽度可以容忍末端偏差，成功可能来自夹爪覆盖范围，而不是策略把末端送到理想中心。

4. **何时停止堆 ACT — 自测问题**
   - 参考答案：r6 在中部随机测试上不如 r5，且 370k→400k 无明显增益，说明继续加步/远侧补数主要是空间权衡而非整体提升；主力使用区（中部）已可用 → 锁 r5，转 SA。

### 面试式自测

1. **为什么远侧变好、近侧变差？**
   - 参考答案：继续训练可能重新分配模型对不同位置和轨迹模式的拟合；远侧样本改善了部分远点，但也可能改变近侧的动作先验或暴露方差，因此两个区域可以出现相反变化。

2. **为什么右近要测 3 次？**
   - 参考答案：右近是边界失败点，单次结果可能受执行噪声影响；重复测试才能估计它的稳定成功率和失败方差。

3. **为什么不同 checkpoint 的成功次数不能直接合并比较？**
   - 参考答案：本轮 200k、300k、370k 的测试位置和重复次数不同，且短边中距离位置尚未补齐；直接合并会把位置覆盖和测试次数差异误当成模型能力差异。

4. **为什么先做 ACT-C0 再做 SharedAutonomy？**
   - 参考答案：先闭合 Manual 采集–训练–部署，才能证明数据与推理链路可用，并为 SA 对照提供可复现的 Manual 基线；否则无法区分「SA 有用」与「链路本身不通」。
